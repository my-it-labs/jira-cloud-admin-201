## Pregunta 1

Cambias el permission scheme compartido por 20 proyectos. El efecto:

- A) Solo el proyecto desde el que editaste
- B) Los 20 al instante
- C) Tras reiniciar Jira
- D) Solo team-managed

<details>
<summary>Ver respuesta</summary>

**B.** Por eso se copian schemes y se nombran. Es poder y riesgo.

</details>

## Pregunta 2

Un proyecto company-managed necesita un issue type extra **solo él**. Lo más limpio:

- A) Editar el issue type scheme compartido (afecta a todos)
- B) Copiar el issue type scheme, añadir el tipo, asociar **solo** ese proyecto
- C) Crear un TMP
- D) Usar un label

<details>
<summary>Ver respuesta</summary>

**B.** Excepción = scheme propio. No rompas la plantilla corporativa.

</details>

## Pregunta 3

«Configure issue field layout» en ACP-620, en CMP, apunta sobre todo a:

- A) Board swimlanes
- B) Screens + field configuration (required/hidden)
- C) Product access
- D) Sprint duration

<details>
<summary>Ver respuesta</summary>

**B.** Layout = qué campos y cuándo. En TMP es la issue layout del propio proyecto.

</details>
